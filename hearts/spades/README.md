# Карточная игра «Пики» (Spades) на Python

Классическая карточная игра «Пики» (Spades) против трёх компьютерных соперников (ИИ).
Проект поддерживает два режима работы: современный **веб-интерфейс на Flask** и классический **консольный интерфейс (CLI)**.

## Требования и установка

- Python 3.10 или выше.
- Зависимости перечислены в файле `requirements.txt` (`flask`).

Установка зависимостей:
```bash
pip install -r requirements.txt
```

## Запуск веб-версии

Для запуска веб-интерфейса выполните любую из команд:

```bash
python -m spades --web
```
или:
```bash
python -m spades.web.app
```

После запуска откройте в браузере:
👉 **[http://localhost:5000](http://localhost:5000)**

### Особенности веб-интерфейса:
- **Тёмная тема** и зелёный суконный стол с объёмными эффектами.
- **Отрисовка карт веером** внизу экрана с анимацией подъёма при наведении.
- **Подсветка допустимых ходов** в соответствии с правилами игры и затемнение запрещённых карт.
- **Интерактивные модальные окна** для выбора ставок (включая Nil), итогов каждого раунда и объявления победителя.
- **Панель счёта команд** с отображением очков и мешков (овертриков).
- **Виджет предыдущей взятки** на столе (отображает победителя и карты предыдущего круга).
- **Всплывающий журнал истории партии** (`/api/history`) с детальным обзором всех завершённых раундов и взяток.
- **Окно правил игры** с быстрым доступом прямо во время партии.
- **Настройка новой партии** с выбором режима правил (Классический до 500 / Быстрый до 250), имени игрока и скорости ходов ИИ.
- **Звуковые эффекты** на базе Web Audio API (раздача, щелчок карты, победа во взятке, победная мелодия) с возможностью выключения.
- **Горячие клавиши**: клавиши `1`–`9`, `0`, `Q`, `W`, `E`, `R` для выбора карт с клавиатуры; `Пробел` для перехода к следующему раунду или рестарта; `Esc` для закрытия окон.

## Запуск консольной версии (CLI)

Консольный интерфейс доступен для запуска следующими способами:

```bash
python -m spades
```
или:
```bash
python spades/main.py
```

### Дополнительные параметры запуска CLI:
- `--name <ИМЯ>` — имя игрока (по умолчанию: `Вы`):
  ```bash
  python main.py --name Алексей
  ```
- `--slow` — паузы между ходами ИИ для комфортного чтения:
  ```bash
  python main.py --slow
  ```
- `--target <ОЧКИ>` — цель очков для победы (по умолчанию: `500`):
  ```bash
  python main.py --target 300
  ```

## Описание REST API

Сервер Flask предоставляет следующие эндпоинты для управления игровым процессом:

### 1. `POST /api/new_game`
Начать новую игру.
- **Тело запроса (необязательно, JSON):**
  ```json
  {
    "player_name": "Вы",
    "scoring_mode": "standard",
    "target_score": 500
  }
  ```
  *(Режимы: `"standard"` — 500 очков, 10 мешков, Nil: ±100; `"short"` — 250 очков, 6 мешков, Nil: ±50)*
- **Ответ:** текущее состояние игры (JSON).

### 2. `GET /api/state`
Получить текущее состояние партии.
- **Ответ:**
  ```json
  {
    "status": "ok",
    "phase": "bidding",
    "round_number": 1,
    "dealer_name": "Запад",
    "is_human_turn": true,
    "spades_broken": false,
    "scoring_rules": {
      "target_score": 500,
      "bags_limit": 10,
      "bag_penalty_points": 100,
      "nil_points": 100
    },
    "hand": [
      {
        "suit": "♠",
        "rank": 14,
        "symbol": "Т",
        "name": "Туз Пик",
        "display": "Т♠",
        "is_valid": false
      }
    ],
    "current_trick": [],
    "last_trick": null,
    "teams": {
      "0": { "name": "Ваша команда", "total_score": 0, "bags": 0 },
      "1": { "name": "Соперники", "total_score": 0, "bags": 0 }
    }
  }
  ```

### 3. `POST /api/bid`
Сделать ставку на количество взяток в текущем раунде.
- **Тело запроса (JSON):**
  ```json
  {
    "bid": 3
  }
  ```
  *(0 для ставки Nil, от 1 до 13 для обычных ставок)*

### 4. `POST /api/play_card`
Сыграть карту из руки игрока.
- **Тело запроса (JSON):**
  ```json
  {
    "suit": "♥",
    "rank": 14
  }
  ```
  *(или `{"card_index": 0}`, или `{"card_str": "Т♥"}`)*

### 5. `POST /api/next_round`
Перейти к следующему раунду после завершения текущего.

### 6. `GET /api/history`
Получить историю всех завершённых раундов и взяток текущей партии.
- **Ответ:**
  ```json
  {
    "status": "ok",
    "history": [
      {
        "round_number": 1,
        "dealer_id": 3,
        "dealer_name": "Запад",
        "bids": { "0": 3, "1": 3, "2": 4, "3": 3 },
        "tricks": [ ... ],
        "score": { ... }
      }
    ]
  }
  ```

## Правила игры

1. **Колода и команды:**
   - 52 карты (от двойки до туза, без джокеров). 4 игрока, 2 команды партнёров напротив друг друга:
     - **Ваша команда:** Вы (Игрок 0) + Восток (Игрок 2).
     - **Соперники:** Север (Игрок 1) + Запад (Игрок 3).
   - Каждому раздаётся по 13 карт.

2. **Козырь:**
   - Постоянный козырь — **Пики (♠)**. Старшинство в масти: 2..10, Валет, Дама, Король, Туз.

3. **Торговля (Bidding):**
   - Каждый игрок по очереди объявляет ставку от 1 до 13 или **0 (Nil)**.
   - Ставки партнёров суммируются в контракт команды.

4. **Розыгрыш взяток:**
   - Обязательно ходить в масть взятки, если есть карты этой масти.
   - Если масти нет — разрешено сбросить любую карту или перебить козырной пикой.
   - **Пики не сломаны (Spades Not Broken):** нельзя начинать взятку с пик, пока пики не были сломаны ранее, за исключением случая, когда на руке остались только пики.

5. **Режимы правил и подсчёт очков:**
   - **Классический режим (Standard):**
     - Цель победы: **500 очков**.
     - Выполненный контракт: 10 очков за заявку + 1 очко за каждый овертрик (мешок).
     - Провал контракта: штраф −10 очков за каждую заявленную взятку.
     - Штраф за 10 мешков: **−100 очков** (мешки сбрасываются mod 10).
     - Ставка Nil: **+100 очков** при 0 взяток, **−100 очков** при 1 или более взятках.
   - **Быстрая партия (Short):**
     - Цель победы: **250 очков**.
     - Штраф за 6 мешков: **−50 очков** (мешки сбрасываются mod 6).
     - Ставка Nil: **+50 очков** при успехе, **−50 очков** при срыве.

## Архитектура проекта

```
spades/
├── core/                  # Чистая библиотека игровой логики (без print/input)
│   ├── __init__.py        # Экспорт основных классов и функций
│   ├── cards.py           # Card, Deck, Suit, Rank
│   ├── players.py         # Player, HumanPlayer, AIPlayer
│   ├── scoring.py         # ScoringEngine, TeamState, PlayerRoundRecord
│   ├── game.py            # SpadesGame, Trick, PlayedCard, GameEvents
│   └── session.py         # GameSession — пошаговый менеджер для Web API
├── web/                   # Flask веб-интерфейс
│   ├── __init__.py
│   ├── app.py             # Flask сервер и REST API эндпоинты
│   ├── templates/
│   │   └── index.html     # Игровой стол, веер карт, модальные окна
│   └── static/
│       ├── style.css      # Тёмная тема, зелёный суконный стол, карты
│       └── script.js      # AJAX-взаимодействие с API, анимация веера
├── cli/                   # Консольный интерфейс
│   ├── __init__.py
│   ├── view.py            # Отображение стола, форматирование и ввод
│   ├── main.py            # Точка входа для консоли
│   └── __main__.py        # Запуск через python -m cli
├── cards.py, game.py...   # Модули обратной совместимости (реэкспорт из core)
├── main.py                # Точка входа консольной игры
├── requirements.txt       # Зависимости (flask)
├── tests/                 # Модульные и интеграционные тесты
│   ├── test_cards.py
│   ├── test_players.py
│   ├── test_scoring.py
│   ├── test_game.py
│   ├── test_core.py       # Тесты пакета core
│   └── test_web.py        # Тесты Flask REST API
└── README.md              # Документация и инструкции
```
